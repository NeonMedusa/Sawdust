# 时间轴 / 行轴滚动条（minimap 语义）——设计文档

> 实现：`src/ui.zig` 的 `scrollbarTimelineEx`（横向，playlist=8 / pianoroll=10）、
> `scrollbarVExt`（纵向，playlist=9）；标准纵向滚动条 `scrollbarV` 供钢琴卷帘/插件列表。
> 竖轴设计先在播放列表验证（用户实测通过），随后横向按同一套移植。

## 一句话概括（用户视角）

> 这个滚动条不是普通滚动条：**滑块 = 你当前看到的那扇窗口在整张地图上的投影**。
> 拖它 = 移动窗口；**拖过头 = 把窗口拖出地图边界**（滑块跟着滑出去、超出部分裁掉，
> 完全出去就看不见了）；拖回来就重新出现。地图本身（总行程）**永远不会被拖动改变**。

## 核心模型：纯投影 + 无界悬空

**滑块是"视口矩形"在地图上的原始投影**（不是"滚动位置手柄"）：

```
地图（content：内容像素 / 行轴为行×行高）
├──────────────────────────────────────────┤
│            ┌──────────┐                  │
│            │  滑块     │ ← 左缘 = 视口左缘
│            │ (thumb)  │    右缘 = 视口右缘
│            └──────────┘                  │
└──────────────────────────────────────────┘
     滑块滑出右端 →          ┌──────────┐
     （超出部分被裁掉）      │  滑块     │ ……
                            └──────────┘
```

### 三条铁律

1. **滑块 = 投影，几何只认两个数**：
   ```
   thumb_top = scroll / 地图长 × 轨道长
   thumb_len = 视口 / 地图长 × 轨道长
   ```
   超出轨道的部分**裁剪绘制**——不压缩、不增长、不改总行程。
2. **滚动可越过地图末端（"悬空"）**：视口可以整个滑出地图，滑块随之消失；
   **上/左端是绝对原点，硬钳 0**；内部另有 `1 << 30` 防溢出帽（交互无感）。
3. **总行程（地图）永不因拖动改变**：地图只有两个来源——调用方推导
   （横：内容右缘+3 小节留白，保底 4 小节；纵：最短行程 128 行/内容下缘+3 行留白）
   + 内容放置后的自然生长。"借出/回收/延长/压缩"这套状态**不存在**。

### 悬空怎么来、怎么回去

- 产生悬空：拖滑块越过端点继续拖 / 中键拖动平移视口 / **垂直滚轮**（用户拍板放开；
  横向没有横向滚轮）；
- **巨图模式（地图 ≥ 10k 小节/轨道，`view_util.overhang_map_limit`）**：
  **拖动滑块不得再出图**（只允许往回；回程不限）；滚轮不受此限；
- 滚轮上限 = 内部防溢出帽（垂直滚轮可一直滚出地图）；
- 悬空的"回收" = 滚回去/拖回去/**点小地图跳回去**——**没有回收状态**。
  （点滑块外空白 = 把点击处放到视口正中，**可以产生悬空**；唯一例外 = 上/左端：
  硬钳 0——不允许反向悬空；巨图模式下点击也不出图）

### 拖动速度：地图比例 1:1

```
scroll = (目标滑块位置 − 轨道起点) × 地图长 / 轨道长
```

鼠标 1px = `地图长/轨道长` 像素内容坐标。这与旧版"过门前的平移速度"**恰好相等**
（`max_scroll/travel == 地图长/轨道长`），所以**过门前后手感天然一致**；
旧版"过门后由滑块反推地图长"的速度按 `1/thumb²` 爆炸（实测：鼠标一毫米≈一屏），已根治。

## 手势总表

| 手势 | 横向（`scrollbarTimelineEx`） | 纵向（`scrollbarVExt`） |
|---|---|---|
| 拖主体 | 地图 1:1 平移；过右端 → 悬空 | 同左；过下端 → 悬空 |
| **点击滑块外空白** | **点击处居中于视口**（可产生悬空）；仅左端例外：硬钳 0 | **点击处居中**；仅上端例外：硬钳 0 |
| 越过近端继续拖 | 硬钳 0（绝对原点） | 硬钳 0（绝对原点） |
| 拖左/右缘（≤8px） | **缩放**（钉住另一端；位移式：零位移恒等；**无“正方形”下限**——可一路压到 1px 线） | 无（□ 缺口包揽） |
| 按下生效区 | 滑块的**可见部分**（完全悬空不响应） | 同左 |
| 光标 | 边缘 `resize_h` | 无 |
| 缩放通路 | 边缘拖 + Ctrl+滚轮 | □ 缺口 + Shift+滚轮 |

## 每帧规范化（唯一的状态卫生）

```zig
// scroll 只钳下界与防溢出帽；地图是只读输入（控件不再书写任何跨度状态）
if (scroll < 0) scroll = 0;
if (scroll > 1 << 30) scroll = 1 << 30;
```

## 缩放与悬空：悬空量保留

所有缩放通路（横：边缘拖 / Ctrl+滚轮 / 缩放补间；纵：□ / Shift+滚轮 / 补间）
都**不把视口拽回地图**——先按锚定公式算出新滚动（该公式自带 [0, 地图−视口] 钳制），
再叠加按下/事件时快照的**悬空量** `over = max(0, scroll − max(0, 地图 − 视口))`。

## 视觉设计

- 滑块**半透明高亮窗**（拖动 a=150 / 悬停 a=120 / 静止 a=70），minimap 内容块
  （片段/音符分布）从滑块下透出——滑块同时就是"视口投影"的可视化；
- 静止用偏白（`scrollbar_light`），悬停/拖动 accent 色；
- minimap 块：**整图不随滚动移动**（地图的概览），滑块在它上面滑动；
- 纵向 minimap 轴换 90°：沿轴 = 行位置，交叉轴 = 片段时间位置（横置里"轨道位置"的角色）。

## 行轴（纵向）特有

- `trackCount()` = 推导跨度（最短 128 行 / 内容下缘+3 行留白）——地图；
- **可见行照常铺到视口底**：悬空时视口下方的行也是"真行"（可点选/命名/放片段）；
  放置 → 内容下缘变深 → 地图生长、滑块按比例重新纳入（"重新纳入的跳变"是预期观感）；
- `view_rows`（视图每帧写入的快照）供右键菜单/重命名等边界守卫；
- 悬空不存档（打开工程滚动归零）。

## 调用方契约

```zig
// 横：地图 = 内容右缘（保底 4 小节）+ 3 小节留白；缩放下限 = 视图恰好容纳整图
timeline_w = (bars_right + 3) × bar_w;
dyn_zoom_min = min(8.0, view_w / timeline_w);
_ = ui.scrollbarTimelineEx(8, x, y, w, h, &scroll_x, timeline_w, &zoom, view_w, dyn_zoom_min, 8.0, mini);
// 纵：
_ = ui.scrollbarVExt(9, x, y, w, h, &scroll, map_rows * row_h, view_h, mini);
```

**id 约定**：播放列表横向 8 / 纵向 9；钢琴卷帘横向 10。

## 相关交互（配套）

- **中键拖动**（两轴）：视口平移，**行走在悬空之上的出口**（无地图上限）——
  拖出去可再拖回；
- **□ 缺口**（`zoomSquare`）：纵向行高缩放（悬空量保留）；横向边缘拖兼作缩放；
- **跟随播放游标**（横向）：行程 = 地图（`content_span`）。

## 附：自然语言模板

> 这是个"窗口投影"滚动条：滑块就是你当前看到的时间窗口。拖它移动窗口；
> **拖过头 = 把窗口拖出地图**（滑块滑出去、看不见了，地图本身不变）；
> 拖回来/滚轮上滚就回到家；**点小地图上滑块以外的空白 = 直接跳过去**（按住还能拖）。横向拖它的左右边缘是拉伸/压缩窗口（缩放）。
