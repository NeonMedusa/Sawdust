# 拖动 / 吸附 / Alt 细调（设计说明）

> 适用：播放列表的**片段**、钢琴卷帘的**音符**；手势包括**移动**与**左右缘拉伸**，
> 单选与**选区批量**都在内。实现分散在 `src/model.zig`（纯数学）、`src/app.zig`（批量与状态）、
> `view_playlist.zig` / `view_pianoroll.zig`（手势接线）。踩坑过程见 `docs/pitfalls.md`。

## 1. 单位与术语

> **数字口径**：本文坐标单位是 `U = 3840`（= **960 PPQN**，见 `docs/units-3840.md`）。
> 文中少数**事故案例里的具体步数**写于 `U = 96`（旧单位）时代——它们是历史证据，
> 保留原数；换算到现行单位就是乘 40。**规则本身与 U 无关。**

| 术语 | 含义 |
|---|---|
| **步**（step） | 最小时间单位。`U = 3840`：1 小节 = 3840 步，1 拍 = 960 步（4/4）。1/16 音符 = **240 步**；1 步 ≈ 0.52 ms @120BPM |
| **网格**（snap） | 一个"档位"（1/1、1/4、1/8、1/16、1/32… 直到 1/3840 = 1 步；另有 1/64~1/384 与三/五连音），决定**每次拖动的步长** |
| **Alt 细调** | 按住 Alt 时网格临时压到 **1 步**（= 1/3840 小节） |
| 位移 `raw` | 鼠标相对**按下点**的累计位移，换算成步：`round((mouse_x − drag_down_x) / (pianoStepPx() · zoom))` |
| 位移 `applied` | 量化后实际生效的位移（步），由 `GridRebase` 产出 |
| **饱和点** `sat_raw` | 值被下限/上限钳住时的那个 `raw`（见 §4 橡皮筋） |

## 2. 八条不变量（改代码前先读这一节）

1. **网格 = 每次位移的步长（增量），不是"把结果吸到网格线"（绝对值吸附）。**
   正确：`新位置 = 原位置 + 量化(位移)`；错误：`新位置 = 对齐(原位置 + 位移)`
   （后者会把脱离网格的对象"传送"到网格线）。
2. **拖动的量化只看"位移"，对象相对网格的偏移被保留。**
3. **Alt 两侧基准不同**：*细调是绝对的（对齐按下点，跟手）*，*粗调是相对的（保住细调成果）*。
   理由与反例见 §3.2。
4. **被钳住只"禁止继续"，不修正已有值（橡皮筋）**：`raw` 无界累积，值钳在边界；
   反向拖动先把超额行程走完，回到"饱和点"那一刻对象精确贴在鼠标下。
5. **量化锚点钉在饱和点**：否则超额行程会污染格子，松 Alt 后长度/位置落在错误的格子上（±2 现象）。
6. **拖动位移用鼠标像素位移算，不能用"内容步相减"**：横向滚动有补间、Ctrl+滚轮会改 zoom，
   那样鼠标不动 `step_i` 也会变（幽灵位移）。
7. **批量钳制是"组级"的**：先算组内极值 → 全体统一停，保持相对间距（不是逐个压扁）。
   **预览与提交必须用同一份钳制逻辑**。
8. **行轴向下无上界**：纵向只钳 0（不许越过第一行），下方不钳（地图随内容生长）。
9. **左缘加长拉不过硬边界，但边界本身要能精确到达**：上限 = 时间轴 0 与内容开头
   （样式片段 `offset` / 音频 `trim_start`）的较小者，**不按网格取整** ——
   剩余余量不足一格时也要能“拉到片段开头”。

## 3. 核心：`model.GridRebase`（位移量化器）

```zig
pub const GridRebase = struct {
    base: i32 = 0,        // 已生效位移（跨网格切换累积）
    anchor: i32 = 0,      // 锚点（raw 空间）
    last_g: i32 = 1,      // 上次用的网格
    sat_raw: ?i32 = null, // 饱和点（钳住时记录）

    pub fn reset(self: *GridRebase, g: i32) void;                  // 新手势：base=anchor=0,last_g=g,sat=null
    pub fn applied(self: *GridRebase, raw: i32, g: i32) i32;       // raw → applied（含切换重锚）
    pub fn settle(self: *GridRebase, raw: i32, g: i32,
                  want: i32, got: i32) void;                       // 把"钳制结果"反馈回去
};
```

### 3.1 普通帧

`applied(raw) = base + snapRound(raw − anchor, g)`
—— 相对锚点量化，所以**偏移被保留**；`snapRound(x, 1) = x`（自由精度）。

### 3.2 切换网格（Alt 按下 / 松开）

| 切到 | 做法 | 效果 |
|---|---|---|
| **细调**（`g == 1`，按 Alt） | `base = 0; anchor = 0` | 值 = 按下时的值 + 鼠标累计位移（**绝对/跟手**）。按 Alt 的瞬间值会朝鼠标**跳最多半格**——有意代价 |
| **粗调**（松 Alt） | `base += snapRound(raw − anchor, last_g); anchor = raw` | 保住当前值（不丢细调成果），之后按新网格整格走（**相对**） |

> **为什么不能两侧都"保持当前值"**：那样切换时鼠标与对象之间的**未兑现子格位移**
> 会在细调下被当成真实位移重算。实测循环：微左移（粗调量化 0）→ 按 Alt → 移回按下点
> （细调 1:1，白赚 +3）→ 松 Alt（保留 +3）→ 重复 → **对象越拖越远离鼠标**。
> 细调改"绝对"后，每次按 Alt 都会把对象拉回鼠标下，净收益恒为 0。

### 3.3 钳住时（`settle`）

```zig
// 调用点：want = 未经钳制的位移，got = 钳制后实际采用的位移
rebase.settle(raw, g, want, got);
```
- 未钳住（`want == got`）：清掉 `sat_raw`，恢复正常跟手；
- 钳住：`sat_raw` 首次记为 `raw − (want − got)`（= 值第一次被钳住时的鼠标位置），
  并令 `base = got, anchor = sat_raw`。

于是 `raw` 仍无界（超额行程保留 → 橡皮筋），而量化格子从"钳住后的真实值"出发（不错位）。

**两种错误做法各自会看到什么**：丢掉超额行程 → 鼠标与对象永久错位
（"鼠标在左、端点立刻跑到右"）；不管它 → 松 Alt 后格子错位（长度落在 `−14+6k`，永远到不了 7）。

## 4. 长度下限：`model.trimFloorLen`

```zig
pub fn trimFloorLen(cur_len: i32, grid: i32, fine: bool) i32 {
    if (fine) return 1;                          // 按住 Alt：自由到 1 步
    return trimMinGridLen(cur_len, grid);        // 否则：从**当前长度**再剥一整格
}
// trimMinGridLen(L, g) = L − floor((L−1)/g)·g
```

- **锚在当前长度**（不是按下时的原长）：`7 步 + 网格 6 → 下限 1`（Alt 缩出来的长度能回去）；
  而 `6 步（= 一格）→ 下限 6` → **拒绝再缩**（再缩一格就是 0 步）。
- 推论（有意）：松 Alt 后若长度是 **8**（非整格），剥一格只能到 **2**，到 2 后拒绝。

## 5. 组级钳制（批量）

| 函数 | 作用 |
|---|---|
| `App.clampClipBatchDelta(d_step, d_track)` | 片段：位移下限 = −组内最小 start；纵向只钳上界 0 |
| `App.clampNoteBatchDelta(d_step, d_pitch)` | 音符：位移下限 = −组内最小 step；音高钳 [0,127] |
| `App.applyClipBatchTrim(delta_steps, grid, fine, left_edge)` | 片段批量拉伸（返回实际应用步数） |
| `App.applyBatchTrim(delta_steps, grid, fine, left_edge)` | 音符批量拉伸 |

批量拉伸的允许量按**当前值**逐成员算、取最严者：
- 缩短 = 各成员“还能剥几整格”的最小值；
- **左缘加长 = 到硬边界为止**（时间轴 0 / 内容开头 `offset` / 音频 trim 头），**不按网格取整**：
  余量不足一格也要能拉到边界（否则永远看不到片段的“真开头”）。

## 6. 手势路径对照表

| 手势 | 位移来源 | 量化 | 钳制 | 落库方式 |
|---|---|---|---|---|
| 片段移动（单个） | `drag_steps` | `rebased.applied` | `max(0, 原起点+位移)` + `settle` | **预览**，松手提交 |
| 片段移动（批量） | 同上 | 同上 | `clampClipBatchDelta` + `settle` | 预览 |
| 片段左右缘拉伸 | `±drag_steps` | 同上 | `trimFloorLen` + 左缘 grow cap + `settle` | 预览 |
| 片段批量拉伸 | 同上 | 同上 | `applyClipBatchTrim` 返回值 + `settle` | **实时**应用 |
| 音符移动（单个，含放置即拖拽） | `drag_steps` | 同上 | `max(0, 原起点+位移)` + `settle` | 实时 |
| 音符移动（批量） | 同上 | 同上 | `clampNoteBatchDelta` + `settle` | 实时 |
| 音符左右缘拉伸 | `±drag_steps` | 同上 | 同上（含 `noteTrimLeft` 二次钳制） | 实时 |
| 音符批量拉伸 | 同上 | 同上 | `applyBatchTrim` 返回值 + `settle` | 实时 |

其余约定：
- **3px 死区**：按下后位移超过 3px 才真正编辑（防单击被吸附）。
- **历史**：手势开始写 `history_pending`，松手 coalesce 提交为一条。
- **片段走预览**：拖动期间**不改模型**，调度器看到的一直是旧位置 → 音频零干扰；
  松手 `commitDragPreview` 一次性写入并触发释音/重扫。
  ⚠️ **预览必须每帧无条件写**（即使新值等于原值）：只在“不一样”时写，
  会在“拖回原值”那一刻漏写 → 画面与 `cur` 停在上一帧，表现为
  “**拉一格不动、拉两格跳两格**”（实测 bug，左/右缘与音频分支都中过）。
- **网格绘制不跟 Alt 变**（只影响编辑量化），否则一按 Alt 网格线瞬间变密。

## 7. 验证清单（改动后必跑）

**模型单测**（`src/model.zig`）：
- `GridRebase：切换网格（按住/松开 Alt）不跳`
- `GridRebase：反复切 Alt 不能"白赚"子格位移（漂移回归）`（10 轮循环恒为 0）
- `GridRebase.settle：橡皮筋（保留超额行程）+ 格子不错位`
- `trimFloorLen：Alt 缩出的 1/96 松 Alt 后能回去`（含 `7/13 → 1`、`12 → 6`、`6 → 6` 拒绝）

**App 单测**（`src/app.zig`）：批量拉伸的整格判据 / Alt 细拖 / 拒绝 / 余数推论；
片段批量拖动撞头全组停；粘贴行号不变。

**手工回归（release 产物）**：

| # | 操作 | 期望 |
|---|---|---|
| 1 | Alt 把 1/16 缩到 1/96，松 Alt（手不松）拉宽一格 | 长度 = 1/96 + 1/16 = **7 步** |
| 2 | 接着往回拉一格 | 回到 **1 步**（不是 6） |

| 6 | 微左移 → 按 Alt → 移回 → 松 Alt，反复十几轮 | 对象始终停原处（不漂） |
| 7 | 选区批量拖到撞轨道头 / 撞 0 步 | 全组一起停，相对间距不变 |

## 8. 已知取舍（都是有意为之）

1. **按 Alt 跳最多半格**（朝鼠标靠拢）——"跟手"的必然代价，换来零漂移。
2. **松 Alt 后长度可能停在非格点**（如 7 步）——细调成果不被抹掉。
3. **非整格长度剥一格会"掉到很低"**（8 → 2）——"以当前网格为单位"的直接推论。
4. **左缘拉长时最后一段可以不足一格**：位移按网格量化，但上限是硬边界（时间轴 0 / 内容开头），
   所以越过边界时会**截停在边界上**（长度/起点因此可以落在非格点）——这是“能看到片段真开头”的必要代价。
5. **超额拖动时对象滞后于鼠标**（橡皮筋），回到饱和点即重新贴住。
6. **拖动中缩放（Ctrl+滚轮）不做特殊处理**：像素→步的换算会随 zoom 变化，属于边缘场景。
