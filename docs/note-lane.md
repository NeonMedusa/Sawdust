# 音符力度/声像编辑轨 — 设计与实现

> 定稿决策：默认力度 **100**；声像方向**上=右（R）/下=左（L）**；
> 轨道高度默认 **220px**（实测合适；小窗由 clamp 收窄）、最小 44px、
> 最大 35%；编辑轨**右键不擦除**（防误删）。背景 = 深灰（`bg`）；
> 纵向网格与钢琴窗同参数（步/拍/小节线），横向参考线 = 值域 32 分 4 格
> + 每格 8 分 4 小格。
> **已实现**（见 `src/view_note_lane.zig`）。

## 布局

```
┌─ 标题栏 ───────────────────────────────────────┐
│ 横向滚动条/minimap + 小节标尺（不动）             │
│ ┌琴键列┐┌──────── 音符区（notes_h）─────────┐   │
│ ═══════ 分割条（splitterH，上下拖）══════════   │
│ │力度/声像│ ▁▃▅▇ 柱条 / 双向柱（编辑轨）        │
└────────────────────────────────────────────────┘
```

- 单轨 + 模式切换（`toggle2`：力度 | 声像），轨道头宽 = `piano_header_w`。
- `PianoState.lane_h`（会话态；0 = 首帧 220px）；分割条拖动改它。
- 横坐标与音符区**同一映射**：`lane_x + step*step_ws − scroll_s`。

## 视觉

每音符一根柱条（力度从底向上、声像从中线双向），末端 = **白色正方形**
（值标记；纵向居中在末端）。**绘制分层**（后画的盖住先画的）：

1. 柱体：未选中组（长→短）→ 选中组（长→短）——选中高亮竖线完整可见；
2. 末端白方块：**全部柱体之后**统一画（长→短）——任何方块都不被
   其他音符的竖条遮住。

- 颜色：选中 → 橙；普通 → 波形绿；末端方块/悬停描边 → 白。
- 背景 = 深灰（`bg`）；纵向网格与钢琴窗同参数（步/拍/小节线），
  横向参考线 = 值域 32 分 4 格 + 每格 8 分 4 小格。

## 数据模型

- `model.Note.velocity: i32 = 100`（1..127）、`model.Note.pan: i32 = 64`（0..127，= CC10 坐标）。
- 存档字段直接加（实验阶段，无需版本升级）。
- 剪贴板携带两字段；`stateEqualsCurrent` 必须比较（否则值编辑不产生历史）。

## 音频

- `Voice.vel_gain = vel/127`；等功率声像 `pan_l/pan_r`（居中 = 1.0/1.0，
  与调音台通道同一公式）；render 逐声部 L/R 累加 + 各自软削波。
- `noteOn(pitch, vel, pan)`；事件（`SchedEvent`/`NoteEvent`）携带 vel/pan。
- 试听也走默认 100 —— 与回放同一响度。

## 播放中编辑：edit_gen 重扫（水位线不回头）

水位线（`scheduled_upto`）只前进：已扫过窗口 `[游标, 水位线)` 内的事件
已入队，改值不重扫就永远听不到。方案：

1. 编辑提交（`commitHistory`）**或手势续接**（`touchGesture`）时 `edit_gen += 1`；
2. **跨游标差分**（旧快照 vs 新数据，键 = 音高+乐器，按数量）：
   新增实例 → `on@游标`（立即发声）；移除 → `off@游标`（防悬挂）；
3. **窗口重扫** `[游标+1, 水位线)`：按新数据重发（带新力度/声像）；
4. 音频侧**触发时过滤**：`ev.gen != gen || ev.edit_gen < edit_gen → 丢弃`
   （不释放声部；stash 不清空——避免 drain 竞态）；
5. 边界取舍：步 == 游标 不重发（可能已触发 → 双触发；漏触发=单音符
   一次不响，轻）。UI 游标滞后音频 ~1 块：滞后窗口内的步会被重触发
   （听感轻微，可接受；悬挂才是严重问题）。

## 交互

> **编辑区不改选区**（实测设计）：力度/声像编辑不应反过来改音符选区——
> 选区只能由钢琴窗建立/取消；编辑区只改值。

| 手势 | 行为 |
|---|---|
| 拖编辑区（起点任意） | 绝对画笔（跟鼠标 y 定值；横扫按 x 序**插值补齐**中间列） |
| 双击柱条 | 重置默认（力度 100 / 声像 64），立即提交 |
| Alt+滚轮 | 调力度/声像：有选区 → 全部选中整体增减；否则 → 最近柱条末端（每格 ±4） |
| 右键 | 无（防误删） |
| 悬停 | 柱条白描边 + 轨道头读数（"力度 96" / "声像 R32"） |

> 画笔的“只编辑选区”判定在**按下那一刻**决定（当时已有选区 → 只刷
> 选中的；否则自由刷）。光标：悬停编辑区**不变光标**。

- 拖动 = 一条历史（`history_pending` coalesce）；拖动中不逐帧重扫，
  松手提交时统一重扫。
- **Alt+滚轮 = 手势合并**（`touchGesture`：起手提交临时条目 + 静置 1s 钉值）；
  每一滚（**含续接**）都即时重扫调度——否则后续滚动要等水位线扫过才生效
  （实测 bug：“Ctrl+A 后 Alt+滚轮改力度不及时生效”）。
- 正在响的音符改值 → 下次触发生效（不能改发声中的声部）。

## 钢琴窗 Alt+滚轮

在钢琴窗音符区 Alt+滚轮同样调力度/声像：最近判定 = **到音符矩形的
曼哈顿距离**（鼠标在矩形内则 0）。有选区时同样整体增减。
（`nearestNoteInPiano`；O(n) 扫描只在滚轮事件时跑，不是每帧。）

## MIDI

- 力度：解析 `ParsedNote.velocity`（此前读了就扔）；导出用音符力度
  （此前写死 100）。
- 声像（CC10）：导入跟踪每通道 CC10 当前值写入音符；导出 best-effort
  插 CC10（声像 ≠ 64 时；同通道去重靠排序后合并写入）。

## 测试

- `view_note_lane.zig`：力度/声像映射往返、钳制、中线吸附、方向；
- `sequencer.zig`：重扫全场景（改值/新增/删除/移动/跨游标差分/不重复）；
- `persist.zig`：力度/声像往返 + 缺字段旧存档 → 默认值；
- `midi.zig`：力度/CC10 导出 → 解析往返；
- `app.zig`：播放中改力度 → 重扫（带新力度）+ 产生历史条目 + 撤销恢复。
